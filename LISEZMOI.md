# STAR MENUISERIES — site web

## Ouvrir dans Visual Studio Code
1. VS Code → **Fichier > Ouvrir le dossier…** → choisir `star-menuiseries`
2. Installer l'extension **Live Server** (Ritwick Dey), clic droit sur `index.html` → **Open with Live Server**
(Connexion internet requise : la 3D et les polices sont chargées depuis un CDN.)

## Modifier le site
- `js/data.js` : produits, prix (en €), couleurs, matières, taux €→DA (`rate`), numéro, e-mail
- Photo d'un produit : ajouter `image:'images/mon-meuble.jpg'` dans le produit (dossier `images/` à créer)
- `js/app.js` : textes français / arabes
- `css/style.css` : design
